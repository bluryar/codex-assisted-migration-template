# TEMP_EXCEPTIONS

## Purpose

This file tracks temporary bridges, fallbacks, compatibility paths, and staged exceptions.

If a temporary mechanism is not listed here, it should not exist.

## Fields

For each exception, record:

- id
- owner
- location
- reason
- allowed callers
- expiry
- delete condition
- current status
